# 🛒 Vinitamart | International E-commerce Solution

**Vinitamart** is a high-performance, scalable e-commerce platform custom-built for a **Vietnam-based client**. This project highlights end-to-end development, from a dynamic storefront to a robust administrative backend.

---

## 🚀 Project Overview

Developed as a freelance project for an international client, Vinitamart aims to provide a seamless shopping experience with a focus on speed, security, and a modern "vibe" in UI/UX.

* **Client Location:** Vietnam 🇻🇳
* **Role:** Lead Full-Stack Developer (Freelance)
* **Status:** Production Ready

---

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React.js, Tailwind CSS, Redux Toolkit |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB (MERN Stack) / MySQL |
| **Auth** | JWT (JSON Web Tokens) & Bcrypt |
| **Tools** | Git, Postman, Vercel/Render |

---

## ✨ Key Features

### 🛍️ User Side
- **Dynamic Product Catalog:** Categorized listing with advanced search and filtering.
- **Responsive UI:** Mobile-first design for a smooth shopping experience on any device.
- **Smart Cart:** Real-time cart updates and persistent storage.
- **Secure Checkout:** Optimized flow for higher conversion rates.

### 🛡️ Admin Dashboard (CMS)
- **Inventory Management:** Add, update, or delete products and categories dynamically.
- **Order Tracking:** Real-time status updates for incoming orders.
- **User Analytics:** Basic insights into sales and user growth.
